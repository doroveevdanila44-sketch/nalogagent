## 3. Как работаем

- Коммиты делаются локально на `main`, пуш делает Даниил через GitHub Desktop. Claude Code не пушит.
- Задания в формате Task, File, Changes, Do NOT touch (и Проверка), без указания модели (`PROMPTS.md`). Одно задание, один коммит с названием из задания.
- Правила текстов (`README.md`): без длинных тире, только дефис или запятая; инициалы слитно («Д.Дорофеев»); интерфейс на русском, числа `ru-RU`, минус «−», валюта «₽».
- Чего не хватает, не придумывать: записать вопрос в `OPEN_QUESTIONS.md` и взять безопасный вариант.
- Числа только из калькулятора. Модель не считает, число в ответе, которого нет в расчёте, значит ответ не уходит (`AGENT.md`).
- Перед коммитом: `npm run typecheck`, `npm test`; для интерфейса `npm run test:e2e` (нужен `npm run db:dev` и системный Chrome). Перед коммитом документов `git diff --cached --numstat` (см. `DECISIONS.md`, раздел «Документы»).
- Изменения схемы идут новой миграцией через `npm run db:generate`; последняя, `0003`, только добавляет таблицы `people`, `checks`, `review_requests`; перед ней `0002` добавила таблицу и колонки (`CALC.md`, раздел «Единая демо-база»).

## 6. Риски и долги

- **Секреты.** Строка Neon и секреты проходили через переписку (со слов владельца). Перевыпустить пароль базы Neon, `PIN_PEPPER` и `SESSION_SECRET`. После смены `PIN_PEPPER` все PIN перестанут подходить: выполнить `npm run user:revoke-devices` (`DEPLOY.md`, раздел 3).
- **Пароль клиента.** Отправлять отдельно, вне приложения и вне переписки с секретами (`AUTH.md`). Файлы `.owner-password.txt` и `.env.neon` лежат на машине открытым текстом (права 600): не копировать в облака и мессенджеры.
- **Правил НДС на 2027 год нет.** С 1 января 2027 дашборд покажет «Нет правил НДС на текущий год» (`OPEN_QUESTIONS.md`, вопрос 8). Агент до этого считает прогноз НДС на 2027 год по трём ставкам при допущениях (выручка 2026 года, лимиты и правила как в 2026, `OPEN_QUESTIONS.md`, вопрос 20); точные лимиты и налог по УСН на 2027 год он объясняет и не считает. Нужны записи в справочнике и подтверждение порога у бухгалтера.
- **Ставки налога на прибыль и УСН условные.** В справочнике у них примечание «Проверить с бухгалтером»; страховые взносы, региональные ставки и льготы не учитываются (`CALC.md`).
- **Neon.** Состояние базы из репозитория проверить нельзя. Код от `194372b` читает таблицу `data_sources`: до выкладки применить миграции `0001` и `0002` и повторить сид (`npm run db:migrate`, `npm run db:seed`). Без повторного сида цвета юрлиц в базе прежние, интерфейс берёт нынешние из `lib/theme.ts` (`DECISIONS.md`).
- **GigaChat не подключён.** Работает заглушка (`LLM_PROVIDER=stub`), значения `gigachat` и `yandexgpt` откатываются на неё с предупреждением в журнале.
- **Перенос на Yandex Cloud** (этап 7) не начат: Dockerfile, Managed PostgreSQL, сертификаты, резервные копии (`DEPLOY.md`, раздел 5).
- **Знак `luxauto41`** набран шрифтом Orbitron вместо логотипа клиента.
- **Данные выдуманные.** Реальные данные клиента подключать только после NDA и обезличивания (`PROMPTS.md`, этап 7).
- **Неподтверждённая проверка.** Поведение чата в Safari на iPhone и в режиме «На экран Домой» не проверялось (в среде разработки iOS нет).

## 7. Открытые вопросы

Полный список в `OPEN_QUESTIONS.md`. Ключевые:

1. Векторный логотип клиента (замена Orbitron и временных иконок PWA).
2. Что показывает зелёная карточка в финале: накопленный налог или прогноз до конца года.
