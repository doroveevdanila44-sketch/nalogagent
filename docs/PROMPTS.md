# Промпты для Claude Code

Запускать по порядку, каждый этап в отдельной сессии или после коммита предыдущего. Перед каждым этапом Claude Code читает `docs/README.md` и `docs/SPEC.md`. В промптах нет указания модели.

---

## Этап 0. Каркас

**Task:** создать проект Next.js с каркасом приложения: шрифты, токены, шапка, нижняя панель, пустые страницы.

**File:** `app/layout.tsx`, `app/(app)/layout.tsx`, `app/(app)/agent/page.tsx`, `app/(app)/dashboard/page.tsx`, `tailwind.config.ts`, `public/manifest.webmanifest`.

**Changes:**
1. `create-next-app` с TypeScript, App Router, Tailwind. Установить `vitest`, `zod`, `decimal.js`, `drizzle-orm`.
2. Шрифт Onest через `next/font/google` ровно по SPEC.md раздел 5. Orbitron только для знака.
3. Токены цветов из SPEC.md в Tailwind.
4. Шапка со знаком `luxauto41` живым текстом, нижняя панель из двух вкладок, поведение на 360 и 1440 px.
5. Манифест PWA, иконки-заглушки, мета для iOS.

**Do NOT touch:** авторизацию, базу, калькулятор. Не добавлять третью вкладку (на этапе 0; позднее правило отменено требованием заказчика и добавлена вкладка «Документы», см. `DECISIONS.md`). Не добавлять вводный текст. Не использовать чистый чёрный цвет.

**Проверка:** `npm run build` проходит, на 390 px нет горизонтальной прокрутки, вкладки переключаются, выбранная вкладка цвета Pale Lemon Yellow `#FFF3B2`.

**Task:** подключить Postgres и создать схему и сиды.

**File:** `lib/db/schema.ts`, `lib/db/client.ts`, `lib/db/seed.ts`, `drizzle/`, `.env.example`.

**Changes:**
1. Схема по `docs/schema.sql` в Drizzle, миграции.
2. Клиент читает `DATABASE_URL`, поддерживает SSL-сертификат из `DATABASE_SSL_CA`.
3. Сид: четыре юрлица, сезонность, правила, помесячная выручка.
4. Скрипт `npm run db:migrate` и `npm run db:seed`.

**Do NOT touch:** код интерфейса. Не использовать Vercel-специфичные хранилища. Не создавать пользователя в сиде.

**Проверка:** миграции и сид проходят на чистой базе Neon, повторный сид идемпотентен.

**Проверка:** все тесты зелёные, расхождение с эталоном не больше 1 ₽.

**Changes:** всё по `docs/AUTH.md`: сценарии 1 до 5, хэши, cookies, лимиты, блокировка по простою, команды владельца, экраны входа и PIN.

**Do NOT touch:** калькулятор и дашборд. Не логировать тела запросов `/api/auth/*`. Не добавлять сброс по почте или SMS. Не показывать PIN или его хэш нигде.
