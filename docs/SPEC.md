# Задание: приложение «Агент по НДС»

## 1. Продукт

Закрытое PWA для собственника группы компаний. Две вкладки после входа:

- **Агент**: чат. Вопросы про НДС, ставки, пороги, прогноз квартала, сценарии. Числа из калькулятора.
- **Дашборд**: группа юрлиц, предупреждения, график выручки, по каждому юрлицу три ставки.

Это не CRM и не учётная система. Автопарка, броней, клиентов, отчётности в приложении нет. Вкладки «Парк» нет, её убрали намеренно.

Вход: логин `luxautoowner` и PIN из 4 цифр (подробно в `AUTH.md`).

## 4. Экраны

### 4.1 Каркас

- **Шапка**: только название «luxauto41» по центру, живой текст, не картинка. Высота около 54 px, фон Vistoris Lake `#A0D2A8`. «luxauto» цветом `#2A2B14` шрифтом Orbitron 500, 22 px, «41» цветом `#784244`, вес 600. Шапка прилипает к верху (`position: sticky`), `safe-area-inset-top` входит в её собственный `padding-top`. Справа меню из трёх точек (блокировка, смена PIN, выход).
- **Нижняя панель** (на телефоне; от 760 px это боковая панель слева шириной 96 px): две вкладки «Агент» и «Дашборд», фиксирована, фон `#2A2B14`, две колонки. Выбранная вкладка: фон Pale Lemon Yellow `#FFF3B2`, текст `#2A2B14`, вес 600. Невыбранная: текст `#E3E6C8`. Иконка 22 px и подпись 12 px. Учитывать `safe-area-inset-bottom`. Пока на телефоне открыта экранная клавиатура, панель скрыта.
- Основная область: контейнер до 1120 px, боковые поля 16 px, нижний отступ с запасом под панель.
- Порядок вкладок: Агент первая, Дашборд вторая. После входа открывается «Агент».
- Вводного текста сверху нет.

### 4.2 Дашборд

1. **Баннер группы.** Фон `#784244`, текст `#FFF8E0`, второстепенный текст `#E8CFCB`. Четыре показателя: выручка с начала года (живая, раз в секунду), НДС начислен (живой), прогноз НДС за год, прогноз налога на прибыль за год. Вид зависит от ширины окна:
   - **От 1024 px (компьютер): один широкий баннер.** Заголовок «Группа на 10 октября 2026», справа «5 юрлиц · УСН и ОСНО», внутри четыре показателя в одном ряду. Баннер не раскрывается: расшифровка по юрлицам есть в карточках юрлиц и на графике ниже.
   - **Ниже 1024 px (телефон и планшет в вертикали): четыре отдельных баннера**, на телефоне друг под другом, на планшете два на два. Нажатие раскрывает расшифровку по юрлицам прямо под баннером: высота плавно растёт за 450 мс (`grid-template-rows` от `0fr` к `1fr`, `cubic-bezier(0.22, 1, 0.36, 1)`), остальные баннеры съезжают вниз, стрелка поворачивается на 180 градусов. Раскрыт один баннер, при открытии другого прежний закрывается одновременно. Фон раскрытой части `#784244`, строки внутри на тон светлее (`#835150`), текст `#FFF8E0`.
2. **Предупреждения**: список из `CALC.md`, у каждого метка «Срочно» (`#B3372B`), «Внимание» (фон `#FFF8D6`, текст `#4A3F00`), «К сведению» (фон `#A0D2A8`, текст `#2A2B14`), счётчик «Срочных: N, всего: M». В списке заголовок, метка и стрелка, пояснение раскрывается по строке (можно несколько сразу).
3. **График выручки группы по месяцам**: столбцы по месяцам, стек по юрлицам цветами юрлиц, прошедшие месяцы сплошные, будущие со штриховкой (прогноз), текущий выделен. Нажатие на сегмент выделяет сегмент юрлица, нажатие на подпись месяца или на пустую область над столбцом выделяет весь столбец (остальные приглушены до 45%, под графиком месяц, итог и разбивка по юрлицам). Доступность: сегменты и подписи месяцев это кнопки с `aria-label`.
4. **Юрлица**: карточка на каждое: название, форма, собственник, статус (плательщик или освобождён), полоса использования порога, три карточки ставок.
   - Выбранная ставка: **зелёная**, показывает живую сумму налога с начала года.
   - Две остальные: **красные**, рассчитываются автоматически, только для сравнения. Нажатие на красную карточку делает её выбранной (сохраняется в `rate_choices`).
   - У освобождённого юрлица подсказка, что НДС сейчас не платится, а суммы показывают налог при переходе порога.
5. Блока «Как считается» нет. Его убрали по просьбе заказчика, не возвращать.

Цвета состояния: зелёный `#1D7A4B` на `#E3F3EA`, красный `#B3372B` на `#FCEAE7`.

### 4.3 Агент

См. `AGENT.md`. Поле ввода низкое: высота 38 px.

### Шрифты

Один шрифт интерфейса: **Onest**, три начертания 400, 500, 600. Курсива и 700 нет, 700 в браузере заменяется на 600. Подключение через `next/font/google` в `app/layout.tsx`: подмножества `cyrillic` и `latin`, `display: 'swap'`, переменная `--font-onest` на теге `<html>`, применяется к `body` (`font-family: var(--font-onest), -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`). Для подключения переменного шрифта указать оси веса одним файлом.

| Вес | Где |
|---|---|
| 400 | Основной текст 16 px, межстрочный 1.45 |
| 500 | Названия строк, подписи вкладок, кнопка «Отправить», время, компактные подписи |
| 600 | Заголовки h1/h2/h3 (24, 19, 16 px), кнопки, метки разделов, суммы, выбранная вкладка |

Числа везде табличные: `font-variant-numeric: tabular-nums` на `body`.

**Единственное исключение:** знак `luxauto41` в шапке и на экране входа набран шрифтом **Orbitron** (500 и 600, подмножество latin, `next/font/google`, подключать только на этих экранах). Это приближение к логотипу клиента. Когда клиент предоставит векторный логотип, заменить текстовый знак на SVG и убрать Orbitron. Вопрос открытый, записать в `docs/OPEN_QUESTIONS.md`.

### Формат чисел

`Intl.NumberFormat('ru-RU')`, минус настоящий «−» (U+2212), рубли «₽» через пробел, миллионы «1,35 млн». Даты по-русски: «18 декабря».

### Адаптивность

Мобильный экран первичен: макеты проверяются на 360, 390, 768, 1024, 1440 px. Нет горизонтальной прокрутки страницы. Целевая область нажатия не меньше 44 px (поле ввода чата 38 px по решению заказчика, остальное 44).

## 6. PWA

- `manifest.webmanifest`: имя «Агент по НДС», короткое имя «НДС», `display: standalone`, `start_url: /agent`, `theme_color: #A0D2A8`, `background_color: #FFFFFF`, иконки 192, 512 и maskable. Иконки сделать из знака (временно: «41» цвета `#784244` на фоне `#A0D2A8`). Цвет полосы под часами (`theme-color`): `#A0D2A8` в приложении, `#784244` на `/login`, экране PIN и блокировке; переключается из кода при смене экрана и блокировке.
- Метатеги для iOS: `apple-mobile-web-app-capable`, `apple-touch-icon`, `viewport-fit=cover`.
- Service worker: кэширует только оболочку (статику, шрифты, иконки). **Данные пользователя, ответы API и страницы после входа не кэшировать**. Офлайн показывает страницу «Нет сети».
- Отсутствие сети не должно оставлять открытым экран с данными: блокировка на PIN работает локально по таймеру.

## 8. Безопасность

- Все страницы кроме `/login` закрыты, API без сессии отвечает 401.
- Заголовки: `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: same-origin`, `Content-Security-Policy` (скрипты и стили свои, шрифты Google только если не используются локальные копии из `next/font`, он их сам размещает).
- Валидация всех входных данных (zod).
- Данные клиента не уходят во внешние сервисы, кроме GigaChat в финале. В демо данные выдуманные.
- Журналы без паролей, PIN и токенов.
- Изоляция: один клиент, одна база, одни ключи. Если появится второй клиент, отдельное развёртывание, не колонка «клиент» в общей базе.

## 9. Критерии приёмки демо

1. Без входа открыть можно только `/login`.
2. Вход `luxautoowner` + пароль, затем создание PIN, затем открывается «Агент».
3. Повторный запуск требует только PIN, после 5 ошибок PIN блокируется.
4. Дашборд показывает четыре юрлица, живые цифры тикают раз в секунду, выбор ставки сохраняется между перезагрузками и устройствами.
5. Контрольные числа из `CALC.md` совпадают в тестах.
6. Чат отвечает на примеры из `AGENT.md` без модели, отказы идут по кругу.
7. Приложение ставится на главный экран на iOS и Android, открывается без адресной строки.
8. Lighthouse: Performance не ниже 85 на мобильном профиле, Accessibility не ниже 95.
9. Развёрнуто на Vercel с Neon, переменные окружения заданы, секретов в репозитории нет.
